# AIHubMix Desktop Releases

Installers and in-app update manifests for AIHubMix Desktop. This repository holds release artifacts only; it contains no source code.

- Download the installer for your platform from [Releases](https://github.com/AIhubmix/aihubmix-desktop-releases/releases/latest).
- In-app updates read `latest.json` from the latest release and install only packages whose signature verifies against the public key built into the app.
